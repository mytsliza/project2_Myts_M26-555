## Управление таблицами

Программа поддерживает следующие команды:

* `create_table <имя_таблицы> <столбец1:тип> ...` — создать новую таблицу. Поддерживаемые типы данных: `int`, `str`, `bool`. Столбец `ID:int` добавляется автоматически.
* `list_tables` — показать список всех таблиц.
* `drop_table <имя_таблицы>` — удалить таблицу.
* `help` — показать справку по командам.
* `exit` — выйти из программы.

### Пример использования:

```text
>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

## CRUD-операции (Работа с данными)

После создания таблиц вы можете добавлять, читать, обновлять и удалять данные. 
Данные каждой таблицы хранятся в отдельном файле в папке `data/`.

Программа поддерживает следующие команды:

* `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавить новую запись. 
  *Значения перечисляются через запятую. Строковые значения обязательно брать в кавычки. Столбец `ID` указывать не нужно — он генерируется автоматически.*
* `select from <имя_таблицы>` — вывести все записи из таблицы в виде красивой таблицы.
* `select from <имя_таблицы> where <столбец> = <значение>` — вывести записи, подходящие под условие.
* `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` — обновить запись.
* `delete from <имя_таблицы> where <столбец> = <значение>` — удалить запись.
* `info <имя_таблицы>` — вывести информацию о таблице (название столбцов и количество записей).

##Primitive DB
Простое консольное приложение на Python, имитирующее работу с базой данных.
Проект реализует базовые операции с таблицами (создание, удаление) и CRUD-операции с данными (добавление, чтение, обновление, удаление).
Данные и метаданные сохраняются в JSON-файлы, а для красивого вывода таблиц используется библиотека prettytable.

##Особенности реализации
Обработка ошибок: Все ошибки (отсутствие файла, неверный тип данных, несуществующая таблица) перехватываются декоратором handle_db_errors и выводятся в понятном виде.

Подтверждение действий: Опасные операции (удаление таблицы или записи) требуют подтверждения пользователя (декоратор confirm_action).

Логирование времени: Некоторые операции (например, insert) замеряют время выполнения (log_time).

Кэширование: Результаты запросов select кэшируются с помощью замыкания для оптимизации повторных запросов.
